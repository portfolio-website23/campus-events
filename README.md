# Campus Events — Static Website

This repository contains a static Campus Event Management website built with Parcel and served with Nginx in Docker.

## Quick start

1. Install Parcel globally: `npm install -g parcel`
2. Install dev dependencies: `npm install`
3. Build static site: `npm run build`
4. Build Docker image: `docker build -t <dockerhub-username>/campus-events:v1 .`
5. Run container: `docker run -d -p 8080:80 <dockerhub-username>/campus-events:v1`
6. Open http://localhost:8080

## Structure
- `src/` - source HTML pages
- `styles/style.css` - shared CSS
- `dist/` - generated by Parcel after build
